# TokenCoin 第一版 Demo

一个围绕“闲置官方 API 调用能力”的交互原型。

第一版只验证一条闭环：**独立卖家自主接入和报价，买家每次调用时由市场自动成交，调用成功后再扣款和分账。**

## 现在可以演示什么

- 买家使用一个人民币余额，在 DeepSeek、Kimi、MiniMax 和 GLM 之间选择模型。
- 平台根据卖家的报价、在线状态、健康度和剩余额度自动撮合。
- 模拟回答以流式方式返回，并生成包含买家实付、卖家收入和平台服务费的交割回执。
- 开启“演示首选卖家超时”后，系统会在回答开始前自动换源，且只扣一次款。
- 卖家可用演示密钥上架新的官方 API 供给，自主设置可售上限和期望到手比例。
- 新的低价供给进入后，买家侧的当前市场价格会立即变化。
- 买家可以查看 Codex、Hermes 和 Cursor 的接入配置示意；后台更换卖家不会改变买家的平台地址和密钥。
- 演示数据保存在浏览器本地，刷新不会丢失，左侧可随时重置。

## 第一版边界

这是交互 Demo，所有供应商、余额、模型回答、报价和调用均为模拟数据。页面不会把密钥上传到服务器，请勿输入真实 API 密钥。

当前没有接入真实厂商 API、支付、提现、身份认证或持久化后端。Plus、Coding Plan、浏览器反代、链上资产、期限交易和 Token 对 Token 兑换不在第一版范围内。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
npm run preview
```

## 推荐演示顺序

1. 在买家页完成一次普通调用，查看交割回执。
2. 开启“演示首选卖家超时”，再次调用，观察自动换源。
3. 进入卖家页，点击“使用演示密钥”，将期望到手价格改为 `0.65`，然后上架。
4. 返回买家页，确认 DeepSeek 活跃供给增加、市场价下降。
5. 再次调用，确认新卖家因更低报价获得订单并产生待结算收入。
